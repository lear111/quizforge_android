## 已对齐行为

- 原 Web 页面、样式、工具栏和交互直接复用，保留草稿全屏；移除手动草稿截图及其快捷键，保留笔迹框选与复制、移动、删除、撤销。
- 一次编辑当前题，未改或撤销回原值可离开；有改动须先保存或取消。刷新／关闭丢弃未保存作者编辑。普通作答、笔迹、图片自动保存不变；旧作者草稿存储仍保留兼容，新页面不调用恢复。
- 删除题库或分组保留拓展与历史，不扫描无关题库或自动清理拓展。
- API 1.5 答题区使用 Web 1.4.1 提供器、1.4.0 模型与 1.0.0 笔刷。文字、图片和宿主笔迹在同一逻辑平面，未声明该能力的旧拓展保持原行为。
- 普通草稿只保存文档与资源引用。提交、完成一轮、考试交卷才剥除客户端旧 snapshot 并生成可信完整逻辑范围 PNG；纯文字不出图。解码、出图、存储或规则失败不会确认残缺提交。
- 可信 renderer 是专用离屏 WebView，只加载固定模型和笔刷；不加载题型 HTML，不接受任意 URL，不接触凭据或通用原生桥，也不截图当前可见页面。图片逐张传输，整题解码和绘制预算受限。旧纯笔迹保留 Web 软件栅格，统一笔迹／混合答案按 2 倍逻辑分辨率合成。
- 冻结历史和考试保存当时的答题区提供器与提交图片。普通题库资源、考试资源及 `history:false` 内存资源各走原作用域，不以落盘绕过临时会话规则。
- AI 沿用现有本地模型与加密凭据。纯文字发送 text；含图片或笔迹时发送已包含该区全部内容的 PNG，不重复发送同区文字。临时附件仅供本次确切引用使用，复验摘要、格式、尺寸及既有 8 张／8 MiB 限制，不写盘。
- 原生和网页“获取题库”继续直达 `https://quizforge.treenewbee.cloud/manage/#library`。
